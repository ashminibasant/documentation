# SRIP-11 CMT Legacy Alias

`CMT` was retired as the SRIP-11 short name in v1.2 because it collides with the
published **Compression Memory Training (CMT)** method.

The canonical specification is:

- [SRIP-11 Structural Memory Compression (SMC)](SRIP-11-SMC.md)

This compatibility page preserves old citations only. It does not define a
second specification or a distinct conformance surface.
